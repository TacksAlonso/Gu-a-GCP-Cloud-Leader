# Understanding Google Cloud Quotas (Comprendiendo las Cuotas de Google Cloud)

Las **Google Cloud Quotas** (Cuotas de Google Cloud) son límites de recursos que ayudan a las organizaciones a controlar el gasto, evitar el **Overloading** (Sobrecarga) de los servicios de Google Cloud y prevenir **Unexpected Spikes** (Picos Imprevistos) de uso.

La mayoría de estos límites de cuota se aplican a nivel de **Project** (Proyecto).

---

## 🛑 Tipos de Cuotas de Google Cloud

Existen tres tipos principales de cuotas diseñadas para limitar diferentes aspectos del consumo de recursos:

| Tipo de Cuota | Objetivo | Concepto de Límite | Ejemplo Clave |
| :--- | :--- | :--- | :--- |
| **Rate Quotas (Cuotas de Tasa)** | Limitar el número de **Requests** (Solicitudes) a una **API** o servicio dentro de un **Time Interval** (Intervalo de Tiempo). | Límite por intervalo de tiempo. | Número máximo de **Compute Engine API Requests** (Solicitudes de API de Compute Engine) por minuto (el valor predeterminado puede ser de 1,500). |
| **Allocation Quotas (Cuotas de Asignación)** | Limitar el uso de **Shared Resources** (Recursos Compartidos) que no tienen una tasa de utilización. | Límite de uso total o absoluto. | Número máximo de **Virtual Machines (VMs)** (Máquinas Virtuales) permitidas por proyecto en un momento dado (ej. un máximo de 20 **VMs**). |
| **Concurrent Quotas (Cuotas Concurrentes)** | Limitar el número total de **Simultaneous Operations** (Operaciones Simultáneas) que pueden estar **In Flight** (En Vuelo) en un momento dado. | Límite de operaciones en paralelo. | **Concurrent Global Operations per Project** (Operaciones Globales Concurrentes por Proyecto), que restringe cuántas llamadas a servicios se pueden realizar en paralelo. |

---

## 💡 Función Clave de las Cuotas

Las cuotas sirven como una herramienta de protección doble:

1.  **Protección del Proveedor:** Evitan que un solo cliente consuma recursos compartidos de manera excesiva, lo que podría sobrecargar el servicio para otros.
2.  **Protección del Cliente:** Ayudan a **Prevent Unexpected Bills** (Prevenir Facturas Inesperadas) al detener automáticamente el consumo si se alcanza el límite preestablecido.
