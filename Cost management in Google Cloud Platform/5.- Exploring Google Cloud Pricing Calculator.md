# Exploring Google Cloud Pricing Calculator (Explorando la Calculadora de Precios de Google Cloud)

El **Google Cloud Pricing Calculator** (Calculadora de Precios de Google Cloud) es la principal herramienta para obtener una **Estimate** (Estimación) del costo mensual de una solución en **Google Cloud Platform (GCP)**. Es fundamental entender que estas son solo **Estimates** (Estimaciones) y **Not Binding** (No Vinculantes) para Google Cloud.

---

## 1. 🔍 Funcionalidad de la Calculadora de Precios

La calculadora permite estimar los costos para casi todos los **Google Cloud Services** (Servicios de Google Cloud), incluyendo:

* **Compute:** **Compute Engine**, **Google Kubernetes Engine (GKE)**, **Cloud Run**, **App Engine**.
* **Storage:** **Cloud Storage**.
* **Data & Databases:** **Cloud SQL**, **Dataproc**, **Pub/Sub**, **Cloud DNS**.

### 💡 La Calculadora como Herramienta de Aprendizaje

Además de estimar costos, la herramienta es valiosa para comprender las **Key Options** (Opciones Clave) y los **Cost Drivers** (Impulsores de Costo) de cada servicio (ej. usar el ícono de interrogación para obtener información detallada de una configuración).

## 2. 💻 Ejemplo de Estimación: Compute Engine

Al configurar una instancia de **Compute Engine (IaaS - Infrastructure as a Service)** (Infraestructura como Servicio) para la estimación, se consideran varios factores de costo:

| Factor de Configuración | Opciones Clave que Impactan el Costo |
| :--- | :--- |
| **Number of Instances** (Número de Instancias) | Cuántas **VMs** se van a desplegar. |
| **Operating System (OS)** (Sistema Operativo) | Elegir entre **Free OS** (SO Gratuito, ej. Linux) o **Paid OS** (SO de Pago, ej. Windows). |
| **Machine Class** (Clase de Máquina) | **Normal** (Disponibilidad y vida útil garantizadas) vs. **Preemptible** (Máquinas más baratas, pero que Google Cloud puede terminar en cualquier momento). |
| **Machine Type Family** (Familia de Tipo de Máquina) | **General Purpose** (Propósito General), **Compute Optimized** (Optimizado para Cómputo), **Memory Optimized** (Optimizado para Memoria), etc. |
| **Region** (Región) | La ubicación geográfica es un factor importante, ya que el precio varía (ej. Iowa vs. Tokio). |
| **Committed Use** (Uso Comprometido) | Comprometerse a 1 o 3 años (adquiriendo **CUDs**) para obtener un **Discount** (Descuento) significativo en el precio. |
| **Runtime** (Tiempo de Ejecución) | Configuración de las horas y días a la semana que el servidor estará activo. |

## 3. 💾 Componentes Adicionales de Costo

La estimación final también debe incluir recursos auxiliares:

* **Persistent Disks (Discos Persistentes):** Se paga en función del **Total Storage Volume** (Volumen Total de Almacenamiento) adjunto a las **VMs**, no por el número de discos.
* **Networking (Redes):** Deben considerarse los cargos por **Egress** (Salida) y transferencia de datos entre regiones.
* **Cloud TPUs:** Si la solución incluye cargas de trabajo de **Machine Learning (ML)**, se debe configurar el uso de **TPUs** (Tensor Processing Units).
* **Single-Tenant Nodes (Nodos de Inquilino Único):** Si se requieren **Dedicated Hosts** (Huéspedes Dedicados) por razones normativas o de seguridad, estos se configuran y añaden a la estimación, siendo significativamente más caros.
