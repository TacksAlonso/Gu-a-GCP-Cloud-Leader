En el apartado de la nube ya no es necesario tener un centro propio fisico, si no que esto se renta, lo cual ofrece un costo mucho mas accesible.

esto se logra por medio de :
- Virtual Machines

- Compute Engine
- Persistent Disk
- Cloud Load Balancing
