# 📊 Exploring Different Data Formats & Corresponding Google Cloud Services (Explorando Diferentes Formatos de Datos y Servicios de Google Cloud Correspondientes)

Los datos se clasifican, a grandes rasgos, en tres formatos principales. Google Cloud ofrece servicios especializados para cada uno de ellos, optimizando el almacenamiento y el análisis.

---

## 1. 🧱 Structured Data (Datos Estructurados)

Los **Structured Data** (Datos Estructurados) se organizan en **tablas** (*tables*), **filas** (*rows*) y **columnas** (*columns*), con un **esquema rígido y bien definido** (*well-defined rigid schema*) y **Relationships** (Relaciones) entre ellas.

| Formato/Características | Google Cloud Services (Servicios de Google Cloud) |
| :--- | :--- |
| **Características:** Bases de datos relacionales, Esquema estricto, Ejemplos: Información de pedidos, Inventario de productos. | **Cloud SQL** (Base de datos relacional transaccional, **OLTP** - Procesamiento de Transacciones en Línea). |
| | **Cloud Spanner** (Base de datos relacional, **Global** y con escala ilimitada). |
| | **BigQuery** (Almacén de datos analítico, **OLAP** - Procesamiento Analítico en Línea). |

---

## 2. 📝 Semi-Structured Data (Datos Semi-estructurados)

Los **Semi-structured Data** (Datos Semi-estructurados) no tienen un esquema fijo, sino que utilizan etiquetas para organizar los datos de forma jerárquica. Esto permite un **Esquema Flexible** (*flexible schema*).

| Formato/Características | Google Cloud Services (Servicios de Google Cloud) |
| :--- | :--- |
| **Características:** Utilizan **JSON** o **XML**. El esquema puede variar entre documentos. Ejemplos: Perfiles de redes sociales, documentos **NoSQL**. | **Cloud Firestore** o **Cloud Datastore** (Bases de datos de documentos **NoSQL**). |
| | **BigQuery** (Puede almacenar documentos **JSON** dentro de sus tablas para análisis). |

---

## 3. 🖼️ Unstructured Data (Datos No Estructurados)

Los **Unstructured Data** (Datos No Estructurados) no tienen una estructura interna definida ni un esquema preestablecido.

| Formato/Características | Google Cloud Services (Servicios de Google Cloud) |
| :--- | :--- |
| **Características:** Archivos binarios, imágenes, vídeos, audio y texto libre. Ejemplos: Archivos de productos, vídeos de vigilancia. | **Cloud Storage** (Almacenamiento en la Nube de objetos, ideal para almacenar **cualquier tipo de dato no estructurado**). |

---

## 🧠 Sinergias y Capacidades Avanzadas

Es importante recordar que los servicios de Google Cloud a menudo pueden trabajar juntos para manejar diferentes formatos de datos:

* **BigQuery y Datos No Estructurados:** Puedes usar **BigQuery ML** (**Machine Learning** en BigQuery) para realizar **ML** (*Machine Learning*) contra **Unstructured Data** (Datos No Estructurados) que se almacenan en **Cloud Storage**. En este escenario, **Cloud Storage** actúa como el repositorio de datos brutos, y **BigQuery ML** proporciona la inteligencia a partir de ellos sin necesidad de mover los archivos a **BigQuery** (análisis federado).
