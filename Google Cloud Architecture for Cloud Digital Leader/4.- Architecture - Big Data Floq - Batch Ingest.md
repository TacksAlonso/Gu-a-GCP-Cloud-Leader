# 📦 Architecture - Big Data Flow - Batch Ingest (Arquitectura - Flujo de Big Data - Ingesta por Lotes)

**BigQuery** (Consulta Grande) es el **preferred big data service** (servicio de big data preferido) en Google Cloud, diseñado para almacenar petabytes de datos y realizar análisis mediante consultas **SQL**. La **Batch Ingestion** (Ingesta por Lotes) es el proceso de cargar grandes volúmenes de datos preexistentes en **BigQuery**.

El flujo de trabajo típico de ingesta por lotes sigue el patrón **ETL** (Extraer, Transformar y Cargar) y comienza con los datos ubicados en **Cloud Storage** (Almacenamiento en la Nube).

## ➡️ Pasos Clave de la Ingesta por Lotes (ETL)

### 1. Extracción (Source)

* **Cloud Storage:** Los datos se transfieren primero a un **Cloud Storage Bucket** (Contenedor de Almacenamiento en la Nube). La fuente puede ser *on-premises* (local), otra **Cloud** (Nube) o cualquier otro sistema de almacenamiento.

### 2. Transformación y Carga (Data Processing)

La elección de la herramienta de transformación depende de la complejidad de la lógica **ETL** requerida:

| Herramienta de Google Cloud | Lógica y Complejidad | Patrón de Uso |
| :--- | :--- | :--- |
| **Dataprep** (Preparación de Datos) | **Simple Data Cleansing** (Limpieza Sencilla de Datos) y transformaciones basadas en reglas. | Se utiliza para limpiar, perfilar y transformar datos con un enfoque más visual y de bajo código. |
| **Cloud Dataflow** (Flujo de Datos) | **Simple Data Pipelines** (Tuberías de Datos Sencillas) y lógica de transformación más compleja que **Dataprep**. | Utiliza plantillas o código **Apache Beam** para la orquestación y transformación de datos. |
| **Cloud Dataproc** (Procesamiento de Datos) | **Complex Processing** (Procesamiento Complejo), incluyendo **Machine Learning (ML)** y **Artificial Intelligence (AI)**. | Se utiliza para ejecutar *jobs* complejos de **Spark** y **Hadoop** sobre los datos antes de cargarlos. |

### 3. Almacenamiento de Destino (Destination)

* **BigQuery:** El destino final de los datos una vez transformados.

## 📈 Visualización y Análisis (Post-Ingestion)

Una vez que los datos están en **BigQuery**, se pueden utilizar herramientas de **Business Intelligence (BI)** (Inteligencia Empresarial) para el análisis y la visualización:

* **Looker:** Una plataforma de BI completa para conectar múltiples fuentes de datos y obtener **Business Intelligence** (Inteligencia Empresarial).
* **Data Studio (Looker Studio):** Una herramienta gratuita para **Visualización** (*Visualization*) de datos, que se conecta directamente a **BigQuery** para crear informes y *dashboards*.
