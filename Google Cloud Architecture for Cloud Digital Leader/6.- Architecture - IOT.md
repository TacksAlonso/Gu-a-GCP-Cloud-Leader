# 💡 Architecture - IoT (Arquitectura - Internet de las Cosas)

La arquitectura de **IoT** (**Internet of Things** - Internet de las Cosas) en Google Cloud se centra en la gestión de dispositivos, la ingesta masiva de datos en tiempo real y el análisis posterior.

## 🔗 Componentes del Flujo de IoT

### 1. Gestión de Dispositivos (Device Management)

* **IoT Core (Núcleo de IoT):** Este es el servicio central para **gestionar, autenticar y autorizar** (*manage, authenticate, and authorize*) los dispositivos **IoT**.
    * **Funciones Clave:** Permite enviar mensajes a los dispositivos (**Downstream**) y recibir datos de **Telemetry** (Telemetría) o métricas desde ellos (**Upstream**).

### 2. Ingesta de Datos (Data Ingestion)

* **Cloud Pub/Sub (Publicación/Suscripción en la Nube):** Es el servicio de **durable message injection** (inyección de mensajes duraderos) que actúa como el primer punto de contacto para todos los datos de **Telemetry** (Telemetría) que llegan desde **IoT Core**.

### 3. Procesamiento y Lógica (Processing and Logic)

La elección del servicio de procesamiento depende de la complejidad de la lógica de negocio requerida:

* **Cloud Functions (Funciones en la Nube):** Una alternativa ligera a **Dataflow** para implementar **lógica sencilla** (*simple logic*). Una **Cloud Function** puede escuchar directamente los mensajes de **Cloud Pub/Sub** y ejecutar tareas rápidas.
* **Cloud Dataflow (Flujo de Datos en la Nube):** Se utiliza para realizar **procesamiento en flujo** (*stream processing*) más complejo
