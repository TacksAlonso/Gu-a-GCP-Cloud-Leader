# 🕸️ Dataplex - Data Mesh in Google Cloud (Malla de Datos en Google Cloud)

Las empresas almacenan una **variedad de datos** (*variety of data*) (**Structured** - Estructurados, **Semi-structured** - Semi-estructurados, **Unstructured** - No Estructurados) en múltiples ubicaciones o **silos** (*silos*): **Relational Databases** (Bases de Datos Relacionales), **NoSQL Databases** (Bases de Datos NoSQL), **Data Warehouses** (Almacenes de Datos) y **Data Lakes** (Lagos de Datos).

El concepto de **Data Mesh** (Malla de Datos) busca resolver esta complejidad proporcionando una visión unificada de todos los **Data Assets** (Activos de Datos).

## ☁️ Dataplex: El Servicio Data Mesh de Google Cloud

**Dataplex** es el servicio de Google Cloud que implementa el concepto de **Data Mesh**. Actúa como un **Single Pane of Glass** (Un Único Panel de Control) para toda su estrategia de datos.

### 🌟 Funcionalidades Clave de Dataplex

1.  **Cross-Silo Data Management (Gestión de Datos entre Silos):**
    * Proporciona gestión de datos a través de diferentes servicios y ubicaciones (silos).
    * Ofrece visibilidad unificada de todos los activos de datos.

2.  **Centralized Security and Governance (Seguridad y Gobernanza Centralizadas):**
    * Permite configurar **Centralized IAM Policies** (Políticas IAM Centralizadas) y aplicarlas de manera uniforme en todos los **Data Sets** (Conjuntos de Datos), independientemente de dónde residan.
    * Asegura políticas de seguridad y gobernanza **Comprehensive** (Exhaustivas).

3.  **Data Discovery and Search (Búsqueda y Descubrimiento de Datos):**
    * Ayuda a los usuarios a **buscar y descubrir** (*search and discover*) dónde se encuentran tipos específicos de datos (ej. números de identificación personal o PII).
    * Se integra con **Data Catalog** (Catálogo de Datos), el servicio de metadatos de Google Cloud, para facilitar el descubrimiento.

4.  **Built-in Data Intelligence (Inteligencia de Datos Integrada):**
    * Se integra de forma nativa con servicios de análisis como **BigQuery** y soluciones de **Data Lake** basadas en **Cloud Storage**, proporcionando capacidades de inteligencia de datos.

> **En Resumen:** **Dataplex** simplifica la gestión de datos distribuidos al proporcionar un punto centralizado para la **Governance** (Gobernanza), la **Security** (Seguridad) y el **Discovery** (Descubrimiento) de los **Data Assets** (Activos de Datos) de una organización en la nube.
