# 🚀 Exploring Important Serverless Services in Google Cloud (Explorando Servicios Serverless Importantes en Google Cloud)

**Serverless** (Sin Servidor) es un modelo de **Cloud Computing** (Computación en la Nube) que permite a los desarrolladores concentrarse exclusivamente en el código, abstraendo la gestión de la **Infrastructure** (Infraestructura) subyacente.

## 💡 Principios de Serverless

1.  **No Server Management** (Sin Gestión de Servidores): El cliente no necesita aprovisionar, configurar ni mantener servidores (VMs).
2.  **Pay-per-Use** (Pagar por Uso): La facturación se basa en el **Consumption** (Consumo) real (invocaciones, tiempo de cómputo, almacenamiento, o transacciones), no en el tiempo de actividad del servidor.
3.  **Automatic Scaling** (Escalado Automático): Los servicios escalan automáticamente en función de la **Load** (Carga) que reciben.

---

## ☁️ Servicios Serverless Clave en Google Cloud

El modelo **Serverless** se aplica a diferentes categorías de servicios en Google Cloud:

### 1. Compute Serverless (Cómputo sin Servidor)

| Servicio | Modelo Serverless | Uso Principal |
| :--- | :--- | :--- |
| **Cloud Functions** (Funciones de Cloud) | **Function as a Service (FaaS)** (Función como Servicio) | Ejecuta código en respuesta a **Events** (Eventos) (ej. una subida a **Cloud Storage** o un mensaje en **Cloud Pub/Sub**). Se paga por el número de **Invocations** (Invocaciones). |
| **Cloud Run** | **Container Hosting** (Alojamiento de Contenedores) | Ejecuta **Isolated Containers** (Contenedores Aislados) de forma **Serverless** (Sin Servidor) y sin necesidad de **Orchestration** (Orquestación). Ideal para aplicaciones que necesitan **Container Portability** (Portabilidad de Contenedores) y escalado automático. |

### 2. Database & Data Warehouse Serverless (Base de Datos y Almacén de Datos sin Servidor)

| Servicio | Tipo de Datos | Beneficio Serverless |
| :--- | :--- | :--- |
| **Cloud Firestore** (o Cloud Datastore) | **NoSQL Document Database** (Base de Datos de Documentos NoSQL) | No requiere creación de servidores. Se paga solo por el **Storage** (Almacenamiento) consumido y el número de **Operations** (Operaciones) realizadas (lecturas/escrituras). |
| **BigQuery** | **OLAP Data Warehouse** (Almacén de Datos OLAP) | Base de datos analítica masivamente escalable. No necesita **Server Provisioning** (Aprovisionamiento de Servidores). El costo se basa en la cantidad de datos almacenados y la cantidad de datos **Processed** (Procesados) por consulta. |

### 3. Messaging & Data Processing Serverless (Mensajería y Procesamiento de Datos sin Servidor)

| Servicio | Tipo de Procesamiento | Beneficio Serverless |
| :--- | :--- | :--- |
| **Cloud Pub/Sub** | **Messaging Service** (Servicio de Mensajería) | Servicio de mensajería **Asynchronous** (Asíncrono) para desacoplar aplicaciones. No necesita preocuparse por los servidores, se paga por el número de **Messages** (Mensajes). |
| **Cloud Dataflow** | **Stream and Batch Processing** (Procesamiento por Flujo y por Lotes) | Plataforma **Unified** (Unificada) para **Data Processing** (Procesamiento de Datos). Escala automáticamente la capacidad de **Compute** (Cómputo) para flujos (**Streams**) y lotes (**Batches**). Se factura solo por el tiempo de procesamiento. |
