# Storage Services in Google Cloud (Servicios de Almacenamiento en Google Cloud)

Google Cloud ofrece una variedad de servicios de **Storage** (Almacenamiento), cada uno optimizado para diferentes tipos de datos, patrones de acceso y requisitos de durabilidad.

---

## 1. 💿 Almacenamiento de Bloques y Archivos (Block and File Storage)

| Servicio | Tipo de Almacenamiento | Caso de Uso Principal |
| :--- | :--- | :--- |
| **Persistent Disk (Disco Persistente)** | **Block Storage** (Almacenamiento en Bloques) permanente. | Funciona como el disco duro conectado a una **Virtual Machine (VM)** (Máquina Virtual) de **Compute Engine**. Es duradero y persistente, incluso si la VM se detiene. |
| **Local SSD** (SSD Local) | **Block Storage** (Almacenamiento en Bloques) temporal y efímero. | Utilizado para **Temporary Storage** (Almacenamiento Temporal) y caché que requiere una latencia extremadamente baja. El dato se pierde si la **VM** se detiene. |
| **Cloud Filestore** | **File Storage** (Almacenamiento de Archivos). | Crear un **Shared File System** (Sistema de Archivos Compartido) en la nube que puede ser montado y accedido por múltiples **VMs** simultáneamente (similar a un servidor NAS). |

> **⚠️ NOTA:** Es fundamental distinguir entre **Cloud Filestore** (Sistema de archivos compartido) y **Firestore** (Base de datos NoSQL).

## 2. 📦 Almacenamiento de Objetos (Object Storage)

* **Cloud Storage (Almacenamiento en la Nube):**
    * Es el servicio de **Object Storage** (Almacenamiento de Objetos) escalable y de alta disponibilidad de Google Cloud.
    * **Casos de Uso:**
        * Almacenamiento de contenido estático generado por usuarios (imágenes, videos, PDFs).
        * Alojamiento de **Static Websites** (Sitios Web Estáticos).
        * **Backup and Archiving** (Copia de Seguridad y Archivo) de grandes volúmenes de datos.
