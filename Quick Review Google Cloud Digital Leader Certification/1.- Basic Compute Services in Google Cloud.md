# Basic Compute Services in Google Cloud (Servicios Básicos de Cómputo en Google Cloud)

Los servicios de **Compute** (Cómputo) en Google Cloud son fundamentales para ejecutar aplicaciones y **Workloads** (Cargas de Trabajo). Estos servicios varían en el nivel de control y el modelo de precios ofrecido.

---

## 1. ⚙️ Compute Engine y Tipos de VM (Virtual Machines)

| Servicio/Concepto | Descripción | Tipo de Servicio |
| :--- | :--- | :--- |
| **Compute Engine (GCE)** | Proporciona **Virtual Machines (VMs)** (Máquinas Virtuales) con sistemas operativos Linux o Windows. Permite el **Full Control** (Control Total) sobre el **Operating System (OS)** (Sistema Operativo) y la instalación de **Custom Software** (Software Personalizado). | **IaaS (Infrastructure as a Service)** (Infraestructura como Servicio) |
| **Preemptible VMs** (VMs Preferentes) | Máquinas virtuales de corta duración (máximo 24 horas) con un **Cost Reduction** (Reducción de Costos) significativa. Google Cloud puede "retirarlas" (**preempt**) en cualquier momento. | Uso recomendado para **Fault-Tolerant** (Tolerantes a Fallos) y **Time-Non-Critical Workloads** (Cargas de Trabajo No Críticas en el Tiempo). |
| **Single-Tenant Nodes** (Nodos de Inquilino Único) | **Dedicated Physical Servers** (Servidores Físicos Dedicados) en los que todas las **VMs** pertenecen únicamente a un cliente. Esto contrasta con la **Shared Tenancy** (Tenencia Compartida) por defecto. | Uso requerido para cumplir con estrictos requisitos de **Security** (Seguridad) o **Licensing** (Licencias). |

## 2. 🗂️ Gestión y Orquestación

| Servicio/Concepto | Descripción | Concepto de la Nube Relacionado |
| :--- | :--- | :--- |
| **Managed Instance Groups (MIGs)** (Grupos de Instancias Gestionadas) | Permiten ejecutar múltiples **Compute Engine VMs** (VMs de Compute Engine) idénticas y **Scale** (Escalarlas) automáticamente. | **Autoscaling** (Autoescalado) |
| **Cloud Load Balancing** (Equilibrio de Carga en la Nube) | Distribuye el **Load** (Carga) del tráfico entrante a través de múltiples **Instances** (Instancias) de una aplicación (a menudo utilizando **MIGs**). | **Networking** (Redes) y **High Availability** (Alta Disponibilidad) |
| **VMware Engine** | Permite a los clientes ejecutar sus cargas de trabajo existentes de **VMware** (para virtualización) directamente en Google Cloud, facilitando la migración. | **Hybrid Cloud** (Nube Híbrida) |
