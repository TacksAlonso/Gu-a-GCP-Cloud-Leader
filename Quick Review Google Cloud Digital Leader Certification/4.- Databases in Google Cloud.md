# Databases in Google Cloud (Bases de Datos en Google Cloud)

Google Cloud ofrece una cartera completa de **Managed Database Services** (Servicios de Bases de Datos Gestionadas) que cubren las necesidades **Relational** (Relacionales), **NoSQL** y **In-Memory** (En Memoria).

---

## 1. ⚙️ Bases de Datos Relacionales (OLTP)

Las bases de datos relacionales utilizan tablas y se consultan mediante **SQL** (Structured Query Language). Se centran en el procesamiento de transacciones en línea (**OLTP**).

| Servicio | Características Clave | Casos de Uso |
| :--- | :--- | :--- |
| **Cloud SQL** | **Regional** (Regional), **Relational** (Relacional), **OLTP**. Compatible con MySQL, PostgreSQL y SQL Server. | Aplicaciones **Transactional** (Transaccionales) con requisitos geográficos limitados. |
| **Cloud Spanner** | **Global** (Global), **Relational**, **OLTP**, **Unlimited Scale** (Escala Ilimitada). Ofrece **99.999% Availability** (Disponibilidad). | Aplicaciones **Globales** con requisitos de **Low Latency** (Baja Latencia) y necesidad de **Horizontal Scaling** (Escalado Horizontal) masivo. |

---

## 2. 🗃️ Bases de Datos NoSQL

Las bases de datos NoSQL están diseñadas para estructuras de datos **schema-less** (sin esquema) que requieren **Rapid Evolution** (Evolución Rápida) o un rendimiento específico.

| Servicio | Características Clave | Casos de Uso |
| :--- | :--- | :--- |
| **Cloud Firestore** | **Serverless** (Sin Servidor), **Transactional Document Database** (Base de Datos de Documentos Transaccional). | Aplicaciones **Web** y **Mobile** (Móviles) de **Small to Medium Size** (Pequeñas a Medianas) (hasta unos pocos terabytes), que necesitan una estructura de datos flexible. |
| **Cloud Bigtable** | **High-Scale NoSQL** (NoSQL de Alta Escala). Diseñado para **Very Large Datasets** (Conjuntos de Datos Muy Grandes). **Importante:** No es **Serverless** (se requiere crear un **Cluster** - Clúster). | **Streaming Workloads** (Cargas de Trabajo de Streaming), **Operational** (Operacionales) y **Analytical** (Analíticas) que requieren **High Throughput** (Alto Rendimiento). |

---

## 3. 🚀 Almacenamiento en Memoria (In-Memory Storage)

| Servicio | Características Clave | Casos de Uso |
| :--- | :--- | :--- |
| **Cloud Memorystore** | **In-Memory Database** (Base de Datos en Memoria) o **Cache** (Caché). Compatible con **Redis** y **Memcached**. | Aplicaciones que requieren respuestas en **Microseconds** (Microsegundos) y necesitan reducir la carga de las bases de datos principales (utilizado para **Caching** de datos). |
