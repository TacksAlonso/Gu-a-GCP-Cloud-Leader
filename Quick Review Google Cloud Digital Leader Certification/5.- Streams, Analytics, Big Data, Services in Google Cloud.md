# Streams, Analytics, Big Data Services in Google Cloud (Servicios de Streams, Analítica y Big Data en Google Cloud)

Google Cloud proporciona una amplia gama de servicios especializados para manejar el **Big Data**, el procesamiento en tiempo real (**Streaming**) y el análisis de datos (**Analytics**).

---

## 1. ⚙️ Messaging and Streaming (Mensajería y Streaming)

| Servicio | Modelo | Descripción y Propósito |
| :--- | :--- | :--- |
| **Cloud Pub/Sub** | **Real-Time Messaging** (Mensajería en Tiempo Real) | Permite construir una **Decoupled Architecture** (Arquitectura Desacoplada) basada en la mensajería. Se utiliza para la ingesta de datos de **Streaming** y la comunicación entre servicios. |
| **Cloud Dataflow** | **Serverless Stream and Batch Processing** (Procesamiento de Streams y Lotes Sin Servidor) | Servicio unificado para procesar grandes conjuntos de datos en tiempo real (**Streaming**) o en bloques (**Batch**). Utiliza el marco de código abierto **Apache Beam**. |

## 2. 🗄️ Data Warehousing and Processing (Almacenamiento y Procesamiento de Datos)

| Servicio | Características Clave | Casos de Uso |
| :--- | :--- | :--- |
| **BigQuery** | **Relational OLAP Database** (Base de Datos Relacional OLAP - Procesamiento Analítico en Línea). **Serverless** y **Highly Scalable** (Altamente Escalable). | Ideal para **Data Warehousing** (Almacenamiento de Datos) y **Big Data Workloads** (Cargas de Trabajo de Big Data) que requieren consultas SQL complejas para el análisis. |
| **BigQuery ML** | **Machine Learning (ML)** dentro de BigQuery. | Permite crear y ejecutar modelos de **Machine Learning** directamente sobre los datos almacenados en **BigQuery** sin necesidad de exportar los datos a otro servicio. |
| **Cloud Dataproc** | **Managed Service for Spark and Hadoop** (Servicio Gestionado para Spark y Hadoop). **Importante:** No es **Serverless** (requiere crear un **Cluster** - Clúster). | Se utiliza para ejecutar trabajos complejos de **Data Processing** (Procesamiento de Datos) utilizando los marcos estándar de la industria (Spark/Hadoop). |

## 3. 📉 Data Orchestration and Visualization (Orquestación y Visualización de Datos)

| Servicio | Propósito | Concepto Clave |
| :--- | :--- | :--- |
| **Cloud Data Fusion** | Gestión visual de **Data Pipelines** (Tuberías de Datos). | Permite **Visually Manage** (Gestionar Visualmente) las rutas y transformaciones de los datos (ETL/ELT). |
| **Looker** (Antes Google Data Studio) | Solución de **Business Intelligence (BI)** (Inteligencia Empresarial). | Herramienta para **Visualize Data** (Visualizar Datos) y crear **Custom Dashboards** (Paneles Personalizados) a partir de conjuntos de datos (ej. datos presentes en **BigQuery**). |
