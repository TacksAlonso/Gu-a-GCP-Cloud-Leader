# Managed Compute Services in Google Cloud (Servicios de Cómputo Gestionados en Google Cloud)

Los **Managed Compute Services** (Servicios de Cómputo Gestionados) en Google Cloud reducen la carga administrativa al manejar la infraestructura subyacente. El cliente solo se enfoca en el código o los contenedores.

---

## 1. 🌐 Plataformas Serverless (Sin Servidor) y PaaS

| Servicio | Modelo | Descripción y Caso de Uso |
| :--- | :--- | :--- |
| **App Engine** | **PaaS (Platform as a Service)** (Plataforma como Servicio) | Despliega rápidamente **Web Applications** (Aplicaciones Web) y **RESTful APIs**. Ideal para aplicaciones Java o Python que buscan una implementación sencilla sin gestionar **VMs**. |
| **Cloud Run** | **Serverless Containers** (Contenedores Sin Servidor) | Ejecuta contenedores **isolated** (aislados) sin necesidad de configurar ni gestionar un clúster de orquestación. Es la opción más sencilla para ejecutar un **Container** (Contenedor) y es compatible con **Knative** (una plataforma abierta para cargas de trabajo de contenedores). |
| **Cloud Functions** | **FaaS (Function as a Service)** (Función como Servicio) | **Serverless Compute** (Cómputo Sin Servidor) para aplicaciones basadas en eventos (**Event-Driven Applications**). El cliente solo paga por las **Invocations** (Invocaciones). |
| **Anthos** | **Hybrid/Multi-Cloud Platform** (Plataforma Híbrida/Multi-Nube) | Proporciona una gestión centralizada para múltiples **Kubernetes Clusters** (Clústeres de Kubernetes) que se ejecutan en diferentes **Clouds** (Nubes) o en el entorno **On-Premises** (Local). |

## 2. 🐳 Orquestación de Contenedores

* **Google Kubernetes Engine (GKE):**
    * Es el **Managed Service** (Servicio Gestionado) de Google Cloud para **Kubernetes** (orquestación de contenedores compleja).
    * Requiere que el usuario cree primero el **Cluster** (Clúster) y luego despliegue las **Workloads** (Cargas de Trabajo) en él.

## 3. 📱 Plataforma de Desarrollo Móvil

* **Firebase:**
    * Aunque no es estrictamente un servicio de cómputo, es la **Mobile Platform** (Plataforma Móvil) de Google.
    * Permite crear aplicaciones para **iOS** y **Android**, además de aplicaciones web y de juegos (usando Unity).
