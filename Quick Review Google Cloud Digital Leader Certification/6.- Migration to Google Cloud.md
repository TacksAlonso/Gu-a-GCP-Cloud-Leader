# Migration to Google Cloud (Migración a Google Cloud)

Google Cloud ofrece una suite de servicios especializados para facilitar la migración de datos, bases de datos y máquinas virtuales (**VMs**) desde entornos **On-Premises** (Locales) u otras **Clouds** (Nubes) a **GCP**.

---

## 1. 💾 Servicios de Migración de Datos y Almacenamiento

| Servicio | Propósito Clave | Tipo de Migración |
| :--- | :--- | :--- |
| **Storage Transfer Service** (Servicio de Transferencia de Almacenamiento) | Transferir grandes volúmenes de datos **Online** (En Línea) directamente a **Cloud Storage** (Almacenamiento en la Nube). | **Data Ingestion** (Ingesta de Datos) |
| **Transfer Appliance** (Dispositivo de Transferencia) | Se utiliza cuando hay una cantidad masiva de datos y es más eficiente transferirlos físicamente mediante el envío de un **Physical Device** (Dispositivo Físico) de Google. | **Offline Data Transfer** (Transferencia de Datos Fuera de Línea) |
| **BigQuery Data Transfer Service** (Servicio de Transferencia de Datos de BigQuery) | Migrar datos analíticos y de **Data Warehouse** (Almacén de Datos) a **BigQuery**. | **Analytics Data Migration** (Migración de Datos Analíticos) |

---

## 2. 💻 Servicios de Migración de Cómputo (Compute Migration Services)

| Servicio | Propósito Clave | Orígenes Soportados |
| :--- | :--- | :--- |
| **Database Migration Service (DMS)** (Servicio de Migración de Bases de Datos) | Mover datos de bases de datos desde el entorno local o de otra nube a **Cloud SQL**. | **On-Premises** y otras **Clouds**. |
| **Migrate for Compute Engine** (Migrate para Compute Engine) | Migrar **VMs** (Máquinas Virtuales) y su **Storage** (Almacenamiento) asociado al servicio **Google Compute Engine (GCE)**. | **VMware**, **Microsoft Azure**, **Amazon EC2**. |
| **Migrate for Anthos** (Migrate para Anthos) | Transformar y migrar **VMs** existentes directamente a **Containers** (Contenedores) que se ejecutan en **Google Kubernetes Engine (GKE)** (gestionado por **Anthos**). | **VMs** a **Containers** (**Modernization** - Modernización) |
