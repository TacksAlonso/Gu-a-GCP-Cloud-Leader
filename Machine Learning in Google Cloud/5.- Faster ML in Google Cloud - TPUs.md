# ⚡ Faster ML in Google Cloud - TPUs (ML más Rápido en Google Cloud - TPUs)

El **Training** (Entrenamiento) de modelos de **Machine Learning (ML)** (Aprendizaje Automático) con millones de **Examples** (Ejemplos) puede llevar semanas o meses. Para acelerar este proceso, Google desarrolló las **Tensor Processing Units (TPUs)** (Unidades de Procesamiento Tensorial).

## 🚀 Tensor Processing Units (TPUs)

Las **TPUs** son **Custom-Designed Processors** (Procesadores Diseñados a Medida) específicamente para ejecutar **Machine Learning Workloads** (Cargas de Trabajo de Aprendizaje Automático).

| Característica | Beneficio |
| :--- | :--- |
| **Speed** (Velocidad) | Son entre **20 y 30 veces más rápidas** que los enfoques de entrenamiento tradicionales (**CPUs** y, a menudo, **GPUs** para ciertas tareas de **ML**). |
| **Iteration** (Iteración) | Permiten a los científicos de datos **Iterate Quickly** (Iterar Rápidamente) en sus modelos y soluciones, reduciendo drásticamente el tiempo de desarrollo. |
| **Efficiency** (Eficiencia) | Están altamente optimizadas para las matemáticas de **TensorFlow** (el *framework* de **ML** de Google), lo que las hace energéticamente eficientes. |

## 🔗 Integración en Google Cloud

Las **TPUs** están diseñadas para integrarse con los principales servicios de **Compute** (Cálculo) de Google Cloud:

* **Compute Engine (Motor de Cómputo):** Se pueden conectar **TPUs** a **Virtual Machines (VMs)** (Máquinas Virtuales) para cargas de trabajo de entrenamiento a gran escala.
* **Google Kubernetes Engine (GKE):** Permite ejecutar cargas de trabajo de **ML** en contenedores con acceso a **TPUs**.
* **AI Platform (Plataforma de IA) / Vertex AI:** La plataforma unificada de **ML** utiliza **TPUs** de manera eficiente para el **Training** (Entrenamiento) y el **Deployment** (Despliegue) de modelos.

> **Conclusión:** Siempre que se trabaje con **Machine Learning** y se necesite reducir significativamente el **Training Time** (Tiempo de Entrenamiento), las **TPUs** deben considerarse la opción principal de **Compute** (Cálculo).
