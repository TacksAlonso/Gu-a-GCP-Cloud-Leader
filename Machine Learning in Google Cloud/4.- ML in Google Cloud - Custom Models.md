# 🛠️ ML in Google Cloud - Custom Models (Modelos Personalizados de ML en Google Cloud)

La creación de **Custom Models** (Modelos Personalizados) permite a las empresas abordar casos de uso muy específicos que los **Pre-Trained Models** (Modelos Pre-entrenados) de las API de Google no pueden cubrir (ej. clasificar tipos específicos de arquitectura). Google Cloud ofrece herramientas para simplificar este proceso, incluso con mínima **ML Expertise** (Experiencia en ML).

---

## 🚀 Opciones para la Creación de Modelos Personalizados

### 1. AutoML (Aprendizaje Automático Automatizado)

**AutoML** simplifica la creación de **Custom Models** (Modelos Personalizados) con un mínimo esfuerzo y **ML Expertise** (Experiencia en ML). El cliente solo necesita proporcionar los datos de ejemplo etiquetados.

| Servicio de AutoML | Tipo de Datos | Propósito |
| :--- | :--- | :--- |
| **AutoML Vision** (Visión) | **Images** (Imágenes) | Extiende **Vision API**. Permite entrenar un modelo para clasificar imágenes en **Custom Categories** (Categorías Personalizadas) (ej. identificar diferentes tipos de casas). |
| **AutoML Video Intelligence** (Inteligencia de Video) | **Videos** (Videos) | Permite realizar **Video Analysis** (Análisis de Video) y detectar/rastrear **Objects** (Objetos) en secuencias de video. |
| **AutoML Tables** (Tablas) | **Structured Data** (Datos Estructurados) | Construye modelos predictivos (ej. predicción de precios de viviendas) utilizando datos estructurados sin requerir que un **Data Scientist** (Científico de Datos) diseñe el modelo. |

### 2. BigQuery ML (BQML)

* **Propósito:** Construir modelos de **Machine Learning** directamente sobre los datos almacenados en **BigQuery** sin tener que exportarlos.
* **Función:** Permite a los usuarios escribir consultas **SQL** simples para **Create, Train, and Deploy** (Crear, Entrenar y Desplegar) modelos.

### 3. Frameworks Estándar

* **Propósito:** Creación de modelos **Complex** (Complejos) y a medida para problemas no estándar.
* **Tecnología:** Utiliza *frameworks* de código abierto como **Tensorflow**, **PyTorch** y **Scikit-learn**. Requiere **Skilled Data Scientists** (Científicos de Datos Cualificados).

---

## 🧠 Plataforma Unificada: Vertex AI

**Vertex AI** es la **Unified AI Platform** (Plataforma de IA Unificada) de Google Cloud.

* **Función:** Se encarga de todo el **Life Cycle** (Ciclo de Vida) de la creación de **ML Models** (Modelos de ML), simplificando las **ML Ops** (**Machine Learning Operations** - Operaciones de Aprendizaje Automático).
* **Alcance:** Soporta todos los tipos de modelos: **Pre-built Models** (Modelos Pre-construidos), modelos de **AutoML** y modelos **Complex** (Complejos) de *frameworks* estándar.
* **Beneficio:** Permite construir y gestionar modelos **faster** (más rápido) al proporcionar un entorno consistente para la ingesta de datos, el entrenamiento, la evaluación, la monitorización y el despliegue.
