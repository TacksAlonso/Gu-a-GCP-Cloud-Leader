# ⚙️ ML in Google Cloud - Pre Trained Models (Modelos Pre-entrenados de ML en Google Cloud)

Uno de los principales desafíos del **Machine Learning (ML)** (Aprendizaje Automático) es el alto costo y el tiempo requeridos para obtener suficientes **Examples** (Ejemplos) y entrenar modelos. Google Cloud resuelve esto ofreciendo **Pre-trained Models** (Modelos Pre-entrenados) listos para usar a través de **APIs** de fácil consumo.

## 🌟 Ventajas de los Modelos Pre-entrenados

* **Ease of Use** (Facilidad de Uso): Se consumen como **APIs** simples de **REST** o **gRPC**.
* **Low Barrier to Entry** (Baja Barrera de Entrada): No se requiere **ML Expertise** (Experiencia en ML) ni grandes conjuntos de datos de entrenamiento por parte del cliente.
* **High Performance** (Alto Rendimiento): Han sido entrenados por Google con vastos conjuntos de datos, asegurando una alta precisión.

---

## 🤖 Modelos Pre-entrenados Clave (APIs de ML)

Google Cloud ofrece APIs específicas para cada dominio de inteligencia artificial:

| Dominio | API de Google Cloud | Propósito |
| :--- | :--- | :--- |
| **Vision (Visión)** | **Cloud Vision API** | Obtener **Intelligence from Images** (Inteligencia a partir de Imágenes). Detecta etiquetas, objetos, caras, hitos, contenido explícito, y lee **Printed Words** (Palabras Impresas) (OCR). |
| **Speech (Voz)** | **Cloud Speech-to-Text API** | Convierte archivos de **Voice** (Voz) o audio en **Text** (Texto) para su procesamiento. |
| **Translation (Traducción)** | **Cloud Translation API** | Traduce texto entre más de **cien idiomas**. |
| **Language (Lenguaje)** | **Cloud Natural Language API** | Obtiene información y estructura (**Insights**) a partir de **Unstructured Text** (Texto No Estructurado) (ej. análisis de sentimiento, clasificación de contenido, extracción de entidades). |
| **Conversational (Conversacional)** | **Dialogflow** | Utilizado para construir **Virtual Assistants** (Asistentes Virtuales) y **Chatbots** basados en voz y texto. |

### Ejemplo: Cloud Vision API

Al proporcionar una imagen a la **Cloud Vision API** (API de Visión en la Nube), el servicio devuelve:

* **Labels** (Etiquetas): Categorías predefinidas asociadas a la imagen (ej. 'cielo', 'nube', 'paisaje') con un **Confidence Score** (Puntuación de Confianza).
* **Object Detection** (Detección de Objetos): Identifica objetos específicos dentro de la imagen.
* **Optical Character Recognition (OCR)** (Reconocimiento Óptico de Caracteres): Lee texto.
