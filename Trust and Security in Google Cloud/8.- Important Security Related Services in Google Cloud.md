# 🛡️ Important Security Related Services in Google Cloud (Servicios Importantes de Seguridad en Google Cloud)

Google Cloud ofrece un conjunto de servicios de seguridad especializados para ayudar a los clientes a implementar una estrategia de **Defense-in-Depth** (Defensa en Profundidad), gestionando la criptografía, secretos, protección de aplicaciones, y postura de seguridad.

---

## 🔑 Criptografía y Gestión de Secretos

### 1. Cloud Key Management Service (Cloud KMS) (Servicio de Gestión de Claves)

* **Propósito:** Se utiliza para **Create and Manage Cryptographic Keys** (Crear y Gestionar Claves Criptográficas).
* **Función:** Aunque Google Cloud proporciona **Encryption by Default** (Cifrado por Defecto) para todos los datos, **KMS** permite a los clientes gestionar y controlar las claves utilizadas para cifrar sus datos (**Customer-Managed Encryption Keys** - Claves de Cifrado Gestionadas por el Cliente).
* **Conceptos:** Las claves se organizan en **Key Rings** (Llaveros).

### 2. Secret Manager (Gestor de Secretos)

* **Propósito:** Almacena, gestiona y asegura el acceso a **Database Passwords** (Contraseñas de Bases de Datos), **API Keys** (Claves de API) y otros **Secrets** (Secretos) de la aplicación.
* **Función:** Evita que se almacenen datos sensibles directamente en el **Application Code** (Código de Aplicación), mejorando la seguridad y las prácticas de **DevSecOps**.

---

## 🔍 Prevención y Descubrimiento de Amenazas

### 3. Cloud Data Loss Prevention (Cloud DLP) (Prevención de Pérdida de Datos en la Nube)

* **Propósito:** Ayuda a **Discover, Classify, and Mask** (Descubrir, Clasificar y Enmascarar) **Sensitive Data** (Datos Confidenciales).
* **Casos de Uso:** Identificación de números de tarjetas de crédito, contraseñas o credenciales de Google Cloud en datos almacenados en **Cloud Storage**, **BigQuery**, o **Cloud Datastore**.
* **APIs:** Las **Cloud DLP APIs** pueden ser invocadas directamente por las aplicaciones para escanear o enmascarar texto en tiempo real.

### 4. Web Security Scanner (Escáner de Seguridad Web)

* **Propósito:** Se utiliza para **Identify Vulnerabilities** (Identificar Vulnerabilidades) mediante la ejecución de **Security Tests** (Pruebas de Seguridad) en aplicaciones web desplegadas.
* **Detección:** Puede encontrar **Cross-Site Scripting (XSS)** (Secuencias de Comandos entre Sitios), **Mixed Content** (Contenido Mixto) y otros **Vulnerabilities** (Vulnerabilidades).

---

## 🛡️ Protección de Aplicaciones y Contenedores

### 5. Cloud Armor (Armadura de la Nube)

* **Propósito:** Protege las aplicaciones web de producción a nivel de borde de la red (**Edge Security**).
* **Funciones:**
    * Protección contra **Distributed Denial of Service (DDoS) Attacks** (Ataques de Denegación de Servicio Distribuido).
    * Mitigación de **Common Web Attacks** (Ataques Web Comunes) basados en la lista **OWASP Top 10** (**Open Web Application Security Project Top 10**).

### 6. Binary Authorization (Autorización Binaria)

* **Propósito:** Asegura que solo se puedan desplegar **Trusted Container Images** (Imágenes de Contenedor Confiables) y **Approved Container Images** (Imágenes de Contenedor Aprobadas) en servicios como **Cloud Run**, **GKE** (**Google Kubernetes Engine**) y **Anthos**.
* **Función:** Aplica políticas de **Deployment** (Despliegue) para evitar la ejecución de código no verificado.

### 7. Container Threat Detection (Detección de Amenazas en Contenedores)

* **Propósito:** Ayuda a detectar **Run-Time Attacks** (Ataques en Tiempo de Ejecución) dentro de los contenedores.
* **Función:** Identifica comportamientos sospechosos, como la descarga y ejecución de **Binaries** (Binarios) dentro del contenedor.

---

## 🔭 Gestión Centralizada de la Postura de Seguridad

### 8. Security Command Center (SCC) (Centro de Comandos de Seguridad)

* **Propósito:** El servicio de seguridad **más importante** y **Unified** (Unificado) de Google Cloud.
* **Funciones Clave:**
    * **Security Posture Management** (Gestión de la Postura de Seguridad): Proporciona una visión consolidada de todo lo relacionado con la seguridad.
    * **Threat Detection** (Detección de Amenazas): Descubre automáticamente **Misconfigurations** (Errores de Configuración) y **Vulnerabilities** (Vulnerabilidades) en los recursos.
    * **Compliance Monitoring** (Supervisión del Cumplimiento): Permite configurar estándares de cumplimiento (ej. **PCI DSS**, **OWASP Top 10**) y supervisa si los recursos cumplen con esas normas, facilitando la creación de **Compliance Reports** (Informes de Cumplimiento).
