# 🔐 Enhanced Security Using 2 Step Verification (2SV) (Seguridad Mejorada Usando la Verificación en Dos Pasos)

La **2 Step Verification (2SV)** (Verificación en Dos Pasos) es una medida de seguridad fundamental que añade una capa de protección a las cuentas de usuario.

## 📝 Verificación en Dos Pasos (2SV)

La **2SV** consiste en **adding a second step to verify the user** (añadir un segundo paso para verificar al usuario).

* **También llamada:** **Multi-Factor Authentication (MFA)** (Autenticación Multifactor).
* **Propósito:** Asegura que incluso si un atacante obtiene la **Password** (Contraseña) de un administrador, no podría acceder a la **Cloud Account** (Cuenta en la Nube) sin el código de verificación adicional, protegiendo así el **Control Plane** (Plano de Control).
* **Ejemplo:** Usar una contraseña (**Something you know** - Algo que sabes) y un código generado en tu teléfono (**Something you have** - Algo que tienes) para acceder.

## 🔑 Mandatory 2SV (Hacer la 2SV Obligatoria)

En **Google Cloud** y para las cuentas de Google asociadas, las organizaciones pueden forzar el uso de la **2SV** mediante diferentes métodos, aumentando la **Data Security** (Seguridad de Datos):

| Método de 2SV | Descripción y Tipo de Factor | Uso en la Nube |
| :--- | :--- | :--- |
| **Security Keys (Llaves de Seguridad)** | Un dispositivo **Physical** (Físico) (ej. llave USB) que debe insertarse. Considerado el método más seguro. | Se utiliza a menudo para cuentas con altos privilegios. |
| **Google Authenticator App (Aplicación Google Authenticator)** | Una aplicación que genera **Time-based One-time Passwords (TOTP)** (Contraseñas de un Solo Uso Basadas en el Tiempo). | El factor de autenticación reside en el dispositivo móvil del usuario. |
| **Backup Codes (Códigos de Respaldo)** | Códigos **One-time use** (De un solo uso) generados e impresos de antemano. | Se utilizan para acceder a la cuenta si el dispositivo primario de 2SV se pierde o no está disponible. |
| **Text Message or Phone Call (Mensaje de Texto o Llamada Telefónica)** | Recibir **2SV codes** (Códigos 2SV) a través de **SMS** o **Voice Call** (Llamada de Voz). | Método común, aunque menos seguro que las Llaves de Seguridad o la aplicación. |
