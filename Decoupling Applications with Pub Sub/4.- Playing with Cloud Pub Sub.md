# 🎮 Playing with Cloud Pub/Sub (Jugando con Cloud Pub/Sub)

**Cloud Pub/Sub** (Publicación/Suscripción en la Nube) es el servicio de **Asynchronous Messaging** (Mensajería Asíncrona) de Google Cloud. Aquí se detalla el proceso práctico y los conceptos clave al interactuar con el servicio.

## 🛠️ Flujo de Creación de Recursos

1.  **Crear un Topic (Tema):** Se define el canal central. Al crearlo, se puede marcar una casilla para generar automáticamente una **Default Subscription** (Suscripción por Defecto).
2.  **Crear Subscriptions (Suscripciones):** Se crean las suscripciones adicionales por las que los consumidores se registrarán en el **Topic**.

### ⚙️ Opciones de Configuración de la Suscripción

Al crear una **Subscription** (Suscripción), se definen parámetros cruciales:

| Opción de Configuración | Propósito | Configuración Común |
| :--- | :--- | :--- |
| **Delivery Type** (Tipo de Entrega) | Define cómo el mensaje es entregado al suscriptor. | **Pull Subscription** (Extracción) o **Push Subscription** (Empuje). |
| **Push Endpoint URL** (URL de Punto Final Push) | Requerido solo para **Push Subscriptions**. Es la URL donde Pub/Sub enviará una solicitud **HTTPS** con el mensaje. | Solo si se selecciona Push. |
| **Message Retention Period** (Período de Retención de Mensajes) | Tiempo que los mensajes **no reconocidos** (*unacknowledged messages*) permanecen almacenados en la suscripción. | Por defecto: 7 días. |
| **Subscription Expiration** (Caducidad de Suscripción) | Si no hay actividad durante un número de días, la suscripción se elimina automáticamente. | Opcional. |
| **Acknowledgement Deadline** (Plazo de Acuse de Recibo) | Tiempo máximo (en segundos) que tiene el suscriptor para **procesar** el mensaje y enviar el **ACK** (Acuse de Recibo). | Por defecto: 10 segundos. |
| **Filter** (Filtro) | Permite que una suscripción reciba **solo ciertos mensajes** (ej. basados en atributos del mensaje). | Opcional. |
| **Dead Letter Topic** (Tema de Carta Muerta) | Tema al que se envían los mensajes si el procesamiento **falla un número configurado de veces** (para evitar fallos infinitos). | Opcional. |
| **Ordering** (Ordenamiento) | Permite la entrega ordenada de mensajes. | Opcional. |

## 📩 Publicación y Consumo de Mensajes

El **Publisher** (Editor) envía mensajes al **Topic**.

### 📝 Proceso de Pulling y Acknowledgement (Extracción y Acuse de Recibo)

1.  **Pull (Extracción):** El suscriptor realiza un **Pull** (Extracción) para obtener los mensajes pendientes de la cola de su suscripción.
2.  **Processing (Procesamiento):** El suscriptor procesa el mensaje. Debe hacerlo **antes** de que expire el **Acknowledgement Deadline**.
3.  **Acknowledgement (ACK - Acuse de Recibo):** El suscriptor envía un **ACK** para indicar que el mensaje fue procesado **exitosamente**.
4.  **Eliminación:** El mensaje **solo se elimina** de la **cola de esa suscripción específica** cuando se recibe el **ACK**.

> **Regla Crítica:** Cuando hay **múltiples suscripciones** en un **Topic**, el mensaje se envía a **TODAS** las suscripciones. Se espera que el mensaje sea procesado y reconocido **individualmente** por cada una de ellas.

### 📸 Snapshots (Instantáneas)

Una **Snapshot** (Instantánea) captura el **estado puntual** (*point-in-time state*) de una **Subscription** (Suscripción).

* **Propósito:** Permite hacer una copia de seguridad o replicar el estado de procesamiento de una suscripción en particular.
* **Recuerda:** Las instantáneas están **relacionadas con una suscripción**, no con un tema.

## 💾 Cloud Pub/Sub Lite (Publicación/Suscripción Lite)

**Pub/Sub Lite** es una variante del servicio optimizada para el **bajo coste** (*low cost*) y el uso de **Journal Storage** (Almacenamiento de Diario).

* **Diferencia Clave:** La replicación en **Pub/Sub Lite** es **Zonal** (lo que lo hace más económico) en comparación con la replicación global de **Pub/Sub** estándar.
* **Recomendación:** Se recomienda **Pub/Sub estándar** para la mayoría de los casos de uso, reservando **Pub/Sub Lite** para escenarios donde el bajo costo es la principal prioridad.
