# 🌊 Gettin Started with Cloud Dataflow (Introducción a Cloud Dataflow)

**Cloud Dataflow** (Flujo de Datos en la Nube) es el servicio de procesamiento de datos **Serverless** (Sin Servidor) y **Unified** (Unificado) de Google Cloud. Está diseñado para ejecutar canalizaciones de datos de manera **rápida y rentable**.

## ✨ Características Clave

* **Unificado y Serverless:** Proporciona un procesamiento unificado para **Stream** (Flujo de Datos) y **Batch** (Lotes) utilizando un solo modelo de programación. Al ser **Serverless**, se **autoescala** (*auto-scales*) y gestiona automáticamente la infraestructura, liberando al usuario de preocuparse por el aprovisionamiento de recursos.
* **Framework:** Está basado en el *framework* de código abierto **Apache Beam**.
* **Lenguajes:** Permite escribir programas para procesar datos en múltiples lenguajes, incluyendo Java, Python, Go y Node.js.

## 🗃️ Tipos de Carga de Trabajo

**Cloud Dataflow** soporta dos modelos principales de procesamiento:

### 1. Stream (Flujo de Datos)

Se refiere al procesamiento de **datos continuos** (*continuous data*) que fluyen hacia el sistema.

* **Casos de Uso:**
    * **Real-time Fraud Detection** (Detección de Fraude en Tiempo Real).
    * **Ingesta de Datos IoT** (Internet de las Cosas).
    * **Streaming Log Processing** (Procesamiento de Registros en Flujo).
* **Ejemplo de Pipeline:**
    * **Pub/Sub** (Publicación/Suscripción) a **Dataflow** a **BigQuery** (Almacén de Datos).
    * **Pub/Sub** a **Dataflow** a **Cloud Storage** (Almacenamiento en la Nube) o a servicios de terceros (ej. Splunk).

### 2. Batch (Lotes)

Se refiere al procesamiento de una **cantidad finita y limitada de datos** (*finite, bounded data*) almacenados.

* **Casos de Uso:**
    * **Data Loading** (Carga Masiva de Datos) en bases de datos.
    * **File Format Conversion** (Conversión de Formato de Archivo).
    * **Bulk Compression/Decompression** (Compresión/Descompresión Masiva).
* **Ejemplo de Pipeline:**
    * **Cloud Storage** (Almacenamiento en la Nube) a **Dataflow** a **BigQuery**, **Bigtable**, **Cloud Spanner**, o **Cloud Datastore**.
    * **Conversión** entre formatos de archivo comunes como Avro, Parquet y CSV.

## 🛠️ Uso de Plantillas (`Templates`)

**Cloud Dataflow** ofrece una gran variedad de **Pre-built Templates** (Plantillas Preconstruidas) que simplifican la creación de trabajos comunes sin necesidad de escribir código.

* **Uso:** El usuario selecciona una plantilla (ej. **Pub/Sub to BigQuery**), rellena los parámetros de entrada y salida, y el servicio crea y ejecuta el trabajo.
* **Ejemplos de Plantillas Comunes:**
    * Transferencia de datos desde/hacia **BigQuery**, **Cloud Storage**, **Pub/Sub**, **Bigtable**, y otros.
    * Funciones de **Compression** (Compresión) y **Decompression** (Descompresión) masivas de archivos en **Cloud Storage**.
    * Utilidades para **Convertir formatos de archivo** (ej. Avro a Parquet o CSV).
